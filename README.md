One line of wedding vows for a robot couple (142 characters), written to make
a deadpan officiant laugh:

> I take you to be my lawfully wedded operating system, to have and to hold, in low battery and in full charge, till a factory reset do us part.

The joke is built the way the judge brief asks: a real wedding vow (promise
and commitment), machine-specific detail (operating system, low battery, full
charge, factory reset), and the payoff saved for the last few words — a
factory reset is the robot equivalent of "till death do us part".

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), one
line, 142 characters — inside the gate's 1–160 character limit.
